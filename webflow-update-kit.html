Round 3 Webflow update

Three embeds changed on each page. Paste each one over the embed with the same number, the same way as the first kit. Nothing else on the page moved, so embeds 03 to 08 stay as they are.

What changes when you paste

  • Five hero options per page, picked by the end of the ad's link. No ?v= means the current headline, so organic traffic sees no change.
  • The hero description now shows on phones. It was hidden under 768px.
  • One line under every form button: Not a broker · Buyers pay our fee · No obligation.
  • A Prefer email first? checkbox on the last step. Leads arrive with contact_preference set to email_first or call, and page_variant still carries the hero.
